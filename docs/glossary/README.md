# Glossaries

One file per language (`<tag>.tsv`, UTF-8, tab-separated, with the header
`term	translation	note`): how the terms of
[translation-glossary.md](../translation-glossary.md) and the words that
recur in eov's interface are translated in that language, for the
application and every plugin alike.

Follow the glossary of your language when you translate, and change it in the
same pull request when you change a term everywhere. Like the translations,
these glossaries were drafted with machine translation and await review by
native speakers and pathologists; corrections are welcome.
